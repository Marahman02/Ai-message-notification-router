🤖 AI Message Notification Router

An AI-powered agent that automatically classifies incoming messages by priority — deciding what deserves immediate attention, what can wait, and what should be silenced.

HackerRank Orchestrate Hackathon — August 2026

🌐 Problem

Modern messaging apps are noisy. Important messages get buried under spam, scams, and low-value forwards. This agent solves that by making intelligent, personalized routing decisions for every incoming message.

🎯 Routing Decisions
notify — interrupt the user now, it's important
digest — useful but not urgent, show later
mute — ignore completely
🛠️ Tech Stack
Python
Claude AI (Anthropic)
Multimodal reasoning (text, images, voice notes)
⚙️ How it works
Safety check — detects prompt injection attacks and fake domains instantly
Context gathering — user history, group info, business verification, past behavior
Claude AI analysis — personalized routing decision per user
Output — results with reason, confidence score, and evidence message IDs
📊 Results on 110 messages
✅ 37 notify
📋 12 digest
🔇 61 mute
